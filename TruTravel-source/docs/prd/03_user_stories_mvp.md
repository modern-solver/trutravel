# MVP User Stories (v0.1)

Format: *As a … I want … so that …* · Priority P0 = launch-critical

## Traveler

| ID | Story | P |
|----|-------|---|
| US-T01 | As a traveler, I want to browse trips by segment first, so I land in the right energy without destination-first clutter. | P0 |
| US-T02 | As a traveler, I want a profile with psychographic + hard prefs, so matching is explainable. | P0 |
| US-T03 | As a traveler, I want to see who is already on a departure (anonymized/aggregate if needed), so I trust group composition. | P0 |
| US-T04 | As a traveler, I want to request/join and pay in INR, so booking is complete in-product. | P0 |
| US-T05 | As a traveler, I want clear cancel/refund policy before pay, so I am not surprised. | P0 |
| US-T06 | As a couple, I want dual-seat Couple Getaway booking, so we are not mixed into solo pools by mistake. | P0 |
| US-T07 | As a builder, I want CodeHouse work-style tags (quiet hours, cowork intensity), so house fit is clear. | P1 |
| US-T08 | As a festival-goer, I want dates locked to the event and optional pass attach, so logistics match the lineup. | P1 |
| US-T09 | As a traveler, I want to message my group after booking, so coordination is not only WhatsApp chaos. | P1 |
| US-T10 | As a traveler, I want to leave a review after trip complete, so trust compounds. | P1 |
