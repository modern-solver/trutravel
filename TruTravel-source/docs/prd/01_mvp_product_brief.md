# TruTravel MVP Product Brief (v0.1)

**Owner:** P1 · **Aligned to:** Shared Context v1.1 · Scope of Action  
**Horizon:** Public MVP beta in 12 weeks (M0–M6)

## Vision (product lens)

A technocratic, segment-first OS where travelers find **like-minded co-travelers** and book **group trips** across six product lines—not a destination OTA.

## Six segments (equal structural weight)

| Segment | MVP promise |
|---------|-------------|
| Trippy Tours | Free-spirited group culture, conscious vibe, clear policy boundaries |
| Thrilling Tours | Adventure / skill-challenge with fitness gates |
| Wellness Tours | Reset, yoga, mind-body curated groups |
| Couple Getaways | Dual-traveler privacy (not dating) |
| CodeHouses | Co-living workation + deep work + optional local days |
| Music + Art Festivals | Crew travel + stay (+ optional pass affiliate) |

## MVP surfaces (must ship)

1. **Segment home** — six archetypes, technocratic density  
2. **Trip / departure card** — price, dates, group composition, captain, operator  
3. **Profile + prefs** — segment tags, constraints  
4. **Matching v0** — rules + tags (explainable)  
5. **Join / request-to-join + book + pay (INR)**  
6. **Group space (MVP chat or equivalent)**  
7. **Trust basics** — verified badge, emergency contact, policies  
8. **Admin / partner** — create departure, assign operator, seat ledger stubs  

## Explicit non-goals (MVP)

- Full OTA (hotels/flights a la carte)  
- Native apps  
- Black-box AI travel agent as primary UI  
- Landlord-owned CodeHouse real estate  
- Primary festival ticket retail (affiliate first)  

## Vertical-slice strategy

Ship **one corridor × one segment** end-to-end before expanding inventory width.

**Recommended first slice (M1 PRD):** Thrilling · Himachal/Uttarakhand · 1 departure  
**Parallel thin inventory (M4):** ≥1 SKU per remaining segment where supply allows
