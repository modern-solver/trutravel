## Naming convention

```
slice_<corridor>_<segment>_<nn>.md
# e.g. slice_himachal_thrilling_01.md
```

## Exit criteria for a slice PRD

- [ ] Problem + JTBD  
- [ ] In / out of scope  
- [ ] Happy path booking flow  
- [ ] Segment-specific constraints  
- [ ] Success metrics  
- [ ] Open questions for founder
