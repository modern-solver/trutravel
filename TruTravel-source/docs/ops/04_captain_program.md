# Community Captain Program (v0.1)

**Tier:** T3 · Volunteer → Host Pro path · **Owners:** G1 + G2

## Role

Captains create culture, fill seats, and act as safety liaison—not full tour operators (unless also T1).

## Entry criteria

- [ ] Profile complete + segment expertise stated  
- [ ] ID verification  
- [ ] Code of conduct accepted  
- [ ] Reference or prior community proof (campus / creator / past trips)  

## Responsibilities

- Pre-trip welcome + norms  
- On-trip vibe + escalation to operator for logistics  
- Post-trip nudge for reviews  
- No side-cash bookings off-platform  

## Incentives

- Credits first until trip **complete + review window**  
- Seat bounty **1–3% of P** (or fixed credit table by segment)  
- Path to paid Host Pro after N successful departures + quality score  

## Quality score inputs

- Traveler NPS on captain  
- Incident-free rate  
- Show-up / communication responsiveness  
- Policy adherence  

## M4 target

≥ **10** captains recruited across launch corridors.
