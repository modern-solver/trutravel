# Anchor Operator Onboarding Checklist (v0.1)

**Tier:** T1 Anchor Operator · **Owner:** G2

## Stage 0 — Lead intake

- [ ] Business legal name + trade name  
- [ ] Primary contact + escalation phone  
- [ ] Corridors served  
- [ ] Segments they can deliver (map to 6)  
- [ ] Sample past itineraries / proof of ops  

## Stage 1 — Verification (before first live departure)

- [ ] KYC lite (ID + business docs per India requirements)  
- [ ] Tourism / guide licenses where applicable  
- [ ] Insurance declaration (what exists / gaps)  
- [ ] Bank / payout details for settlement  
- [ ] Emergency SOP acknowledgment  

## Stage 2 — Commercial

- [ ] Tier terms agreed (settlement %, volume bonuses)  
- [ ] Refund matrix acknowledged  
- [ ] Content rights (photos)  
- [ ] Non-disparagement / review response norms  

## Stage 3 — First SKU

- [ ] Trip QA checklist passed (`03_trip_qa_checklist.md`)  
- [ ] Captain assigned or platform captain pool  
- [ ] Price, capacity, inclusions locked  
- [ ] Admin status: **Approved → Live**  

## Stage 4 — Live ops

- [ ] Pre-trip roster confirmed T-48h  
- [ ] Incident channel tested  
- [ ] Post-trip settlement ticket opened after complete + review window  

## Red flags (do not onboard)

- Cannot name permits for high-risk activities  
- Cash-only, no invoice trail  
- Refuses refund matrix or emergency contact
