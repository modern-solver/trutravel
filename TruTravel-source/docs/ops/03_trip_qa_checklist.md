# Trip QA Checklist (v0.1)

**Gate:** No public listing without QA pass · **Owner:** G2 · **Risk review:** A4

## Identity

- [ ] Segment assigned (exactly one primary)  
- [ ] Corridor assigned  
- [ ] Departure dates / timezone clear  
- [ ] Capacity + waitlist policy  

## Product clarity

- [ ] Day-by-day itinerary  
- [ ] Inclusions / exclusions  
- [ ] Fitness / skill / couple / CodeHouse / festival constraints stated  
- [ ] Meeting point + end point  
- [ ] Packing / gear notes  

## Safety

- [ ] Risk level (1–5)  
- [ ] Emergency contacts (operator + local)  
- [ ] Medical / altitude / water / nightlife notes as relevant  
- [ ] Trippy: policy boundaries language reviewed  
- [ ] Festival: crowd + travel between venues plan  
- [ ] CodeHouse: house rules, quiet hours, guest policy  

## Commercial

- [ ] Seat price P in INR  
- [ ] Platform take rate band applied  
- [ ] Cancel/refund copy matches matrix  
- [ ] Affiliate attach (pass/gear) documented if any  

## Trust content

- [ ] Operator verified  
- [ ] Captain assigned or “TBA by T-7” rule  
- [ ] Photos rights cleared  
- [ ] No misleading scarcity
